# Network Analysis Standard

1. Define the investigation question and traffic scope.
2. Identify relevant hosts, ports and protocols.
3. Use Wireshark filters to reduce noise.
4. Follow TCP/HTTP conversations and inspect DNS activity.
5. Review Suricata alerts and associated metadata.
6. Correlate IDS alerts with packet-level evidence.
7. Assess whether the activity is benign, suspicious or malicious.
8. Document evidence, conclusion and recommended action.

Keep packet analysis reproducible by recording the filters and key frames used.

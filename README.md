# Network Traffic Analysis — Wireshark & Suricata

**SOC Analyst L1 Portfolio Project · Network Detection & Investigation**

> **Status: Active / evidence library being expanded**

## Objective
Develop the ability to investigate raw network traffic with Wireshark and correlate packet-level observations with IDS alerts from Suricata.

## Investigation Workflow

1. Acquire or generate traffic in an authorized lab environment.
2. Use Wireshark filters to isolate relevant hosts, protocols, ports and conversations.
3. Follow TCP/HTTP streams and inspect DNS activity.
4. Run traffic through Suricata and review generated alerts.
5. Correlate IDS alerts with the underlying packets.
6. Document malicious, suspicious or benign conclusions with evidence.

## Example Analysis Areas

- Port scanning and reconnaissance
- Suspicious network connections
- DNS anomalies
- HTTP activity
- Beaconing indicators
- IDS alert validation

## SOC Skills Demonstrated

Wireshark · PCAP analysis · Suricata concepts · packet-level investigation · IDS correlation · network anomaly analysis

## Evidence Roadmap

The repository is being expanded with sanitized PCAP screenshots, Suricata alert examples and analyst-style case notes. No sensitive network data will be published.

## Scope & Ethics

Traffic analysis is limited to authorized lab environments and public/educational datasets.

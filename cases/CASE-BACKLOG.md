# Network Investigation Case Backlog

Planned cases are promoted to completed investigations only after packet/IDS evidence has been captured and validated.

| ID | Scenario | Primary evidence | Status |
|---|---|---|---|
| NET-001 | Port scanning / reconnaissance | PCAP + Suricata alerts | Planned |
| NET-002 | Suspicious DNS activity | DNS packets + alert context | Planned |
| NET-003 | HTTP credential exposure | HTTP stream + packet evidence | Planned |
| NET-004 | Beaconing-style traffic | Time-series packet analysis + IDS telemetry | Planned |

## Completion standard

Each case should contain traffic scope, filters used, relevant frames, timeline, IDS correlation, analyst verdict and recommended action.
